## Which Lambda type?

This lab uses a
<Tooltip term="web-function" label="Web Function" />.

| Type | Use when |
| --- | --- |
| **Web Function** | HTTP — Express, Hono, SSR, streaming |
| **Event Function** | Events — SQS, S3, EventBridge, streams |
| **MicroVMs** | Untrusted or isolated sandbox workloads |

## Three resources

A Web Function has revisions and endpoints:

- <Tooltip term="web-function" label="Web Function" /> `wf-hello` — the resource
- <Tooltip term="revision" label="Revision" /> — immutable code + config (`Pending` → `Active`)
- <Tooltip term="endpoint" label="Endpoint" /> `dev` — HTTPS URL that routes to an Active revision

Traffic only when the **endpoint** and the **revision** are both Active.

No API Gateway adapter. Each environment serves many concurrent requests.
`maxConcurrencyPerEnvironment` (revision setting) bounds concurrency — range
1–128, default 64. See
[Scaling behavior for Lambda Web Functions](https://docs.aws.amazon.com/lambda/latest/dg/web-functions-scaling.html).
