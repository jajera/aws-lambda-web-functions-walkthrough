Skip if Hello World was enough — still [tear down](/teardown/) afterward.
Pass the [CLI gate](/prerequisites/#cli-gate-optional-path) before path B.

Both paths use `demo/` and create a new revision under **Latest revision**.

## A — console zip

Fewer leftovers than `deploy`.

```bash
cd demo
```

```bash
npm ci --omit=dev
```

```text
added 65 packages, and audited 66 packages in 470ms

28 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities
```

```bash
zip -rq ../wf-hello.zip index.js package.json package-lock.json node_modules && ls -lh ../wf-hello.zip
```

```text
-rw-rw-r-- 1 johna johna 870K Oct 15 06:57 wf-hello.zip
```

Console → `wf-hello` → upload `wf-hello.zip` as a new revision → wait
**Active**. Native modules need **Arm64** (this demo has none).

## B — CLI deploy

May create an IAM role and S3 objects — clean up in [Teardown](/teardown/).

```bash
aws lambda-web deploy --name wf-hello --code ./demo --region us-east-1
```
