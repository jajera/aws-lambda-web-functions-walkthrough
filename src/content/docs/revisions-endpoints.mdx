<Tooltip term="revision" label="revision" />

`dev` show **Active**. Then copy the HTTPS domain.

## Revisions

Open the **Revisions** tab.

![Revisions tab for wf-hello with latest revision Active](/images/console-revisions-tab.png)

A revision is an immutable snapshot of code and config. New code creates a new
revision. With **Latest revision** auto-deployment, traffic moves to each new
Active revision.

## Endpoints

On **Overview**, under **Endpoints**, open `dev`. Wait for **Active**, then
copy the domain (shape `….lambda-web.<region>.on.aws`).

![Overview for wf-hello with endpoint dev Active and HTTPS domain](/images/console-revisions-endpoints-overview.png)
