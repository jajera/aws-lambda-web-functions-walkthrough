Delete `wf-hello` when you finish. That removes the function, endpoints, and
revisions.

Console Hello World only → step 1. If you ran `aws lambda-web deploy`, also do
step 2.

## 1. Delete function

**Console:** Web Functions → `wf-hello` → **Delete**. Type `confirm`, then
**Delete**.

![Delete function wf-hello dialog with confirm typed](/images/console-teardown-delete-confirm.png)

**CLI:**

```bash
aws lambda-web delete-web-function --function-name wf-hello --region us-east-1
```

## 2. Leftovers (CLI deploy only)

`delete-web-function` leaves the deploy role, S3 objects, and log groups.

### S3 objects (keep the shared bucket)

```bash
aws s3 rm s3://awscli-lambdaweb-123456789012-us-east-1-an/lambda-web/wf-hello/ --recursive
```

```text
delete: s3://awscli-lambdaweb-123456789012-us-east-1-an/lambda-web/wf-hello/20261014T175526Z-acabc763.zip
delete: s3://awscli-lambdaweb-123456789012-us-east-1-an/lambda-web/wf-hello/20261014T110705Z-937789c5.zip
```

Replace `123456789012` and the bucket suffix with yours (`awscli-lambdaweb-…`).
Delete objects only — not the bucket if shared.

### CloudWatch log groups

```bash
aws logs delete-log-group --log-group-name /aws/lambda/web/wf-hello --region us-east-1
```

```bash
aws logs delete-log-group --log-group-name /aws/lambda/web/wf-hello.local --region us-east-1
```

### IAM role

Execution role for the CLI deploy (not a second function):

```bash
aws iam delete-role-policy --role-name awscli-lambdaweb-wf-hello --policy-name awscli-lambdaweb-logs
```

```bash
aws iam delete-role --role-name awscli-lambdaweb-wf-hello
```
